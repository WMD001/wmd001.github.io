### 语法格式

```markdown 
{% swiper [width:max] [effect:cards/coverflow] %}
![img](src)
{% endswiper %}
```

### 切换效果

使用 `effect` 属性来设置图片切换效果，可选值有 `cards` 和 `coverflow`。

{% note color:yellow 注意 一个页面只能设置一次，第一个`swiper`容器的效果全局生效 %}

## 属性

| 属性     | 说明     |
|--------|--------|
| width  | 设置宽度   |
| effect | 图片切换效果 |
